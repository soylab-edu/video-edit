생성 제공업체 검증은 모의 게이트웨이로 수행했고 실제 유료 생성이나 Codex API 추론을 수행하지 않았다. 사용자 인증 연결 후 별도로 검증해야 한다.

BandIt 검사는 음성+합성 음악의 짧은 혼합 샘플로 추론/출력 경로를 확인한 것이며, 다양한 실전 음원에서 분리 품질을 측정한 벤치마크가 아니다. CPU 테스트는 짧은 입력에서도 1분 이상 걸릴 수 있다. GPU 사용 및 긴 영상 처리는 별도의 성능 검증 대상이다.

스크린샷: `test-results/editor-desktop.png`, `editor-mobile.png`, `auto-report.png`. 테스트 산출물과 다운로드 모델/의존성은 Git에서 제외되며 개발 환경의 로컬 저장소에 남는다.

- 브라우저 localStorage 삭제 후 서버 프로젝트 복원, 로그아웃/재로그인, 390px 화면, JS 오류 0을 확인했습니다.
- 공식 OpenAI 기기 인증 페이지와 실제 코드를 발급하고 취소했습니다. 사용자 계정 승인과 Codex 추론은 수행하지 않았습니다.
- 중계의 요청 크기 제한(413)에 대응하는 분할 업로드와 숨김 데이터 경로의 인증된 미디어 전송을 수정했습니다. 순서·크기·다른 소유자·미완료 업로드 차단을 통합 검사합니다.
- 비밀번호 해시 저장, 미인증 접근 차단, 프로젝트 충돌 차단, 재시작 후 세션·프로젝트 유지, 로그아웃 세션 폐기를 검사합니다.

## 2026-10-05 접속 복구 (한국 시간)

편집 서버는 정상이고 외부 연결 프로세스가 사라진 상태를 확인했습니다. 무료 임시 주소 연결에는 기본 재연결이 적용되지 않는 라이브러리 동작을 확인하고, 종료된 연결 프로세스를 다시 시작하는 감시 처리를 추가했습니다. 감시 처리 단위 검사와 실제 외부 연결 프로세스 종료 후 새 주소로 자동 복구를 확인했습니다. 새 주소에서 TLS를 검증하는 HTTPS 요청으로 편집기 HTML·JavaScript, 최초 설정 상태, API 정상 응답, 미인증 미디어 401을 확인했고 사용자 계정/프로젝트는 초기화하지 않았습니다. 이번 Chromium 재검사는 현재 클라우드 프록시 인증서 신뢰 문제로 실행되지 않았으며 TLS 검증을 끄지 않았습니다. 전체 자동 검사는 8개 통과했습니다.

## 2026-10-05 연결 실행 보완 및 로컬 개발 이전 준비

외부 연결 감시기가 다시 종료됐고 편집 서버는 계속 실행 중임을 확인했습니다. 종료 원인을 단정하지 않았습니다. `preview-background.mjs`로 감시기를 명령의 입출력·터미널과 분리하고 파일 로그·PID 기록을 남깁니다. 감시기의 종료 결과와 시그널도 기록하도록 보완했습니다. 명령 종료 후 감시기 생존, 재실행 시 같은 PID 재사용, 기존 재시작 단위 검사 통과, 실제 HTTPS HTML·health·기존 계정 상태 200 및 미인증 소재 조회 401을 확인했습니다. 장시간 유지나 주소 고정은 검증·보장하지 않습니다.
