# HTTPS 작업실

이 클라우드에서는 사용자 요청에 따라 **비밀번호로 보호된 임시 HTTPS 작업실**을 제공합니다. 로컬 개발 환경 이전은 [별도 안내](local-development.md)에 정리했습니다. Tunnelmole 무료 임시 연결이며, 앱과 연결 프로세스가 살아 있는 동안만 유효합니다. 재시작 시 주소가 달라질 수 있습니다. 고정 도메인·상시 호스팅을 배포했다고 표현하지 않습니다.

## 시작과 접속

```bash
cd /workspace/video-edit
npm run build
NODE_ENV=production COOKIE_SECURE=1 PORT=3002 MOA_HOST=127.0.0.1 MOA_DATA_DIR=/workspace/video-edit/.data/live-workspace node --use-env-proxy --use-system-ca server/index.mjs
```

위 서버를 실행한 상태에서 클라우드 Linux의 백그라운드 연결 감시기를 시작합니다:

```bash
PORT=3002 node --use-env-proxy --use-system-ca scripts/preview-background.mjs
```

감시기는 터미널 입출력과 분리해 실행하며 `.data/preview-state/monitor.log`에 기록합니다. 같은 명령을 순차 재실행하면 기존 감시기를 재사용합니다. `.data/preview-state/address.json`의 실제 HTTPS 주소로 내부 확인 후 사용자에게 전달합니다. 개발 중 전경 실행이 필요하면 기존 `npm run preview:public`을 사용할 수 있지만 두 실행 방식을 동시에 시작하지 마세요. 새 작업실은 서버에서 다음 명령으로 발급한 **최초 설정 링크**를 사용합니다. 이 링크의 `#invite` 부분은 24시간 유효하며, 비밀번호를 설정하면 즉시 폐기됩니다. 링크를 공개 저장소·로그에 붙이지 마세요.

```bash
MOA_DATA_DIR=.data/live-workspace npm run invite -- <출력된-HTTPS-주소>
```

사용자는 링크에서 12자 이상 비밀번호를 정한 뒤 편집기에 진입합니다. 이후 같은 주소와 비밀번호로 로그인합니다. 외부 공개 시 `NODE_ENV=production`, `COOKIE_SECURE=1`을 유지하세요. 인증 없는 개발 서버를 외부 연결하지 마세요.

**기존 사용자의 `.data/live-workspace`를 삭제하거나 초기화하지 마세요.** `access/account.json`은 비밀번호 해시와 작업실 소유권, `access/sessions.json`은 해시된 로그인 세션입니다. 미디어·프로젝트·Codex 로그인은 이 디렉터리 아래 보존됩니다. 테스트 초기화는 실제 사용자에게 링크를 전달하기 전, 테스트로만 생성된 작업실에 한정했습니다.

## 연결이 끊겼을 때

`No matching tunnelmole domain`은 편집 서버로 연결되는 임시 도메인이 현재 등록되어 있지 않다는 뜻입니다. 초대 코드의 24시간 유효기간과는 별개입니다. 먼저 편집 서버의 상태를 확인하고, 기존 외부 연결이 없다면 `PORT=3002 node --use-env-proxy --use-system-ca scripts/preview-background.mjs`로 다시 연결합니다. 종료 코드·시그널과 재연결 시각은 감시 로그 및 주소 상태 파일에 기록합니다. 로그의 보존 한도는 시작할 때 2 MiB를 넘으면 이전 파일로 교체하는 방식이며 실행 중 자동 순환은 하지 않습니다.

시작 스크립트는 연결 프로세스가 끝나면 1~30초 간격으로 다시 시작합니다. 재연결 상태와 새 주소는 `.data/preview-state/address.json`에 기록합니다. 무료 임시 연결이므로 **재연결 시 주소가 바뀔 수 있고**, 클라우드 환경 자체가 종료되면 감시 프로세스도 중단됩니다. 고정 주소나 상시 운영을 보장하지 않습니다.

계정과 프로젝트는 초기화하지 않습니다. 기존 계정이면 원래 비밀번호로 로그인합니다. 최초 설정 전이라면 `npm run invite`로 만료된 설정 링크만 새로 발급합니다.

## 사용 흐름

1. 미디어 가져오기 → 파일 선택 → 보관함의 `+`로 타임라인에 추가.
2. 재생 위치 이동 → 가위 또는 `S`로 분할. 속성에서 트림·속도·색·소리 조절.
3. 자동 저장 문구가 `작업실에 저장됨`인지 확인. 다른 브라우저에서도 같은 비밀번호로 최근 프로젝트를 복원합니다.
4. 내보내기 → 영상 내보내기 → 완성된 영상 다운로드.
5. 플러그인 → Codex 로그인 → ChatGPT 계정으로 연결 → 공식 OpenAI 페이지에서 발급된 코드로 승인.

Codex 기기 인증을 ChatGPT 설정 → 보안에서 허용해야 할 수 있습니다. ChatGPT 로그인 방식은 해당 계정의 Codex 구독 사용량·제한을 따릅니다. API 키를 직접 연결하면 API 사용료가 적용됩니다. 호스트 계정의 인증을 가져오지 않습니다. 로그아웃은 작업실 잠금이며, Codex 인증을 완전히 제거하려면 플러그인 화면에서 연결을 해제하세요.

로그인 후 플러그인 화면에서 Runway·Magnific·HeyGen·PixVerse 실행 도구를 조회합니다. ‘다시 조회’로 도구와 인증 상태를 갱신합니다. ‘실행 연결 확인됨’인 카드의 ‘Codex로 작업하기’를 누르고 작업 지시와 참조를 선택합니다. 보고서의 작업·소재·예상/미확인 비용을 검토해 승인하면 실제 실행합니다. ‘제공업체 재인증 필요’는 해당 제공업체가 이 서버의 호출에 UNAUTHORIZED를 반환한 상태입니다. ChatGPT에서 해당 앱 연결을 갱신한 뒤 다시 조회하세요. Codex 로그인 자체를 해제할 필요는 없습니다. BandIt DnR 음원 분리는 별도 플러그인 없이 기본 기능으로 사용합니다.

미디어 썸네일 오른쪽 위 휴지통으로 개별 삭제하거나 ‘샘플 모두 삭제’로 샘플 영상과 음악을 함께 제거합니다. 삭제는 확인 후 해당 작업실 보관함과 현재 타임라인에 적용되며 새로고침해도 유지됩니다. 실행 취소를 위해 원본 파일은 보관하므로 디스크 용량을 비우는 영구 삭제와는 다릅니다.

## 전송·저장

- 로그인하지 않은 방문자는 미디어·편집 API를 읽거나 실행할 수 없습니다. 개인 작업실 하나를 위한 로그인으로, 다중 사용자 서비스 가입 기능은 아닙니다.
- 업로드는 512 KiB 단위로 나누어 전송합니다. 무료 임시 연결의 요청 크기 제한을 고려한 전송 방식이며, 전체 파일 한도는 500MB입니다. 네트워크 중단 시 파일을 다시 선택하세요.
- 서버에서 업로드 순서·크기·소유권을 검사하고 완료 후 FFmpeg로 편집용 파일을 준비합니다.
- 프로젝트는 서버에 저장하고, 브라우저에도 비상 사본을 유지합니다. 두 창이 충돌하면 덮어쓰지 않고 프로젝트 파일 저장을 안내합니다.
- 임시 연결의 HTTPS는 중계 서비스에서 종료됩니다. 이 서비스를 경유해 업로드·다운로드합니다. 고정 호스팅으로 이전할 때는 해당 서버에 직접 TLS를 적용하세요.
- 작업 큐는 메모리에 있으므로 렌더링 도중 재시작하면 작업을 다시 요청해야 합니다. 미디어와 저장 완료 프로젝트는 디스크에 남습니다.

## 검증

`tests/public-browser.mjs`는 **새 테스트 작업실 전용**입니다. 실제 사용자 작업실에서는 실행하지 마세요. 공개 HTTPS 주소에서 가입 대신 최초 비밀번호 설정, 영상 업로드, 재생, 분할, 서버 저장, MP4 다운로드와 FFprobe 검사, 브라우저 사본 제거 후 복원, OpenAI 로그인 코드 발급과 취소, 모바일 화면, 로그아웃/로그인을 검사합니다. TLS 검증을 끄지 않습니다.

`Dockerfile`, Compose와 로컬 시작 파일은 로컬 전환을 위한 초안입니다. 사용자가 로컬 환경 구축을 검토하기 시작했지만 실제 PC에서의 빌드·자료 이전은 아직 진행하지 않았습니다.
