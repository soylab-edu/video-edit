# Moa Studio

초보자를 위한 한국어 웹 영상 편집기. React · TypeScript · Vite, Node/Express와 FFmpeg를 사용합니다.

배포 목표는 **각자 Windows PC에서 사용하는 설치형 프로그램**입니다. 현재 웹 편집 화면과 로컬 편집 엔진을 기반으로 개발하며 중앙 웹서비스 운영은 목표가 아닙니다. Windows 설치 파일과 자동 실행 패키징은 아직 구현하지 않았습니다.

## 접속

외부 HTTPS 개인 작업실 접속·비밀번호 설정·Codex 로그인 방법은 [접속 안내](docs/access.md)를 참고하세요. 현재 클라우드 접속은 무료 임시 연결이며 고정 호스팅은 아닙니다. 로컬 개발 환경으로 이전할 때는 [로컬 이전 안내](docs/local-development.md)를 참고하세요. 실제 PC에서의 설치·실행은 아직 검증하지 않았습니다.

## 개발 실행

Node 24+, Python 3.12, FFmpeg 7+, `uv`, Noto Sans CJK가 필요합니다. 이 클라우드 환경에는 설치되어 있습니다.

```bash
cd /workspace/video-edit
bash scripts/setup.sh
npm run dev
```

웹은 5173, API는 3001 포트를 사용합니다. 빌드 후 `NODE_ENV=production npm start`는 웹과 API를 3001에서 함께 제공합니다. 프로세스는 스냅샷으로 복원되지 않으므로 새 작업에서 다시 시작합니다.

```bash
npm run build
npm test               # 실제 FFmpeg 입출력, 승인/세션 격리
npm run test:browser   # dev 서버 실행 중; 시스템 Chromium 필요
```

## 편집 기능

- 영상·이미지·오디오 업로드, 웹 재생용 변환, 썸네일과 보관함
- 소재별 삭제와 샘플 전체 삭제. 샘플 삭제는 작업실별로 저장되어 새로고침해도 복원되지 않습니다. 타임라인에서도 제거하며 실행 취소를 위해 원본 파일은 보관합니다.
- 재생/탐색, `S` 분할, 인점/아웃점 수정, 드래그 순서 변경, 복제/삭제, 실행 취소/복원
- 클립 재생 속도·볼륨·밝기·채도, 시간 지정 텍스트, 별도 오디오 트랙
- 무음 분석/장면 감지 후 검토 적용, 오디오 추출, 선택적 -16 LUFS 정규화
- H.264/AAC MP4 내보내기: 16:9 1280×720, 9:16 720×1280, 1:1 1080×1080, 24fps
- 서버 자동 저장과 브라우저 비상 사본, 프로젝트 JSON 저장/열기. JSON에는 미디어가 포함되지 않아 같은 보관함이 필요합니다.

샘플은 직접 생성한 일러스트와 합성 앰비언트입니다. `MOA ORIGINAL`은 미리보기 장식으로 출력에는 포함되지 않습니다. 파형은 트랙 구분용 시각화이며 분석한 실제 파형이 아닙니다.

## AI 자동편집

1. **로컬**: FFmpeg로 무음 분석·대사 보존·컷 길이 조정·정규화·1차 렌더링. 외부 전송 및 생성 크레딧이 없습니다. 자유 문장 지시는 로컬 규칙 엔진이 해석하지 않습니다.
2. **Codex 위임**: 대표 프레임(최대 18개), 클립 정보, 무음 분석으로 편집 계획을 만들고 서버가 범위를 검증해 실행합니다. 전체 영상·대사를 모두 이해한다고 가정하지 않습니다. ChatGPT 로그인은 해당 계정의 Codex 사용 한도를, API 키 연결은 API 과금을 따릅니다.
3. **보완 보고**: 적용한 컷·전후 길이·추가 생성 제안을 표시합니다.
4. **일괄 승인**: 작업 목록·전송 자료·통화별 총 견적을 확인하고 승인한 후에만 생성합니다. 순차 처리하며 실패 시 이후 작업을 시작하지 않습니다. 이미 시작된 작업은 제공업체 정책에 따라 과금될 수 있습니다.

원본은 ‘이 편집본으로 계속하기’를 누르기 전까지 보존하며 적용 후에도 실행 취소할 수 있습니다. 별도 오디오/텍스트는 원래 시작점을 유지하고 새 길이까지 제한하므로 대사 자막 타이밍은 검토해야 합니다.

감독 선택: 없음 / 놀란 / 스필버그 / 봉준호 / 웨스 앤더슨. [실제로 읽은 출처 및 편집 규칙](docs/director-research.md). 숫자 프리셋은 제품의 해석이며 감독별 모델 훈련이나 완전한 스타일 재현을 뜻하지 않습니다.

## BandIt DnR 로컬 분리

외부 플러그인 없이 대사(speech)·음악(music)·효과음(effects)을 분리합니다. [공식 소스](https://github.com/kwatcharasupat/bandit)의 `840d5eb9ede59d64569c423244547e58cb00f647` 버전과 [Zenodo](https://zenodo.org/records/10160698)의 `dnr-3s-mus64-l1snr.ckpt`(약 446MB)를 사용합니다. 다운로드 및 실행 시 공식 체크섬을 검증합니다.

```bash
.venv/bin/python scripts/setup-bandit.py --list
.venv/bin/python scripts/setup-bandit.py --file dnr-3s-mus64-l1snr.ckpt --config dnr-3s-mus64-l1snr
.venv/bin/python scripts/bandit-runner.py --check
```

오디오 → 사운드 분리 → 원본 선택 → BandIt으로 3종 분리. 가중치가 없으면 비활성화됩니다. 44.1kHz, CPU 2스레드, 6초 창/3초 홉/배치 1을 사용합니다. 짧은 소스는 임시 패딩 후 원래 길이로 복원하고 동일 스테레오는 한 번 계산합니다. CPU는 실시간보다 느릴 수 있고 음원 누출이 생길 수 있습니다. 배포 시 공식 소스·가중치 라이선스를 확인하세요.

## Microsoft TTS

기본은 `edge-tts`로 Microsoft Edge 온라인 음성 서비스에 연결합니다. 선희·인준·Jenny, 말하기 속도 조절, 생성 후 미리듣기/타임라인 추가를 지원합니다. 별도 API 키를 요구하지 않지만 서비스 정책·가용성은 따르며 Azure TTS 계약을 대신하지 않습니다. 버튼에 텍스트 전송 동의를 표시합니다.

`scripts/tts.py`는 HTTPS 프록시와 OS 인증서를 사용하고 TLS 검증을 유지합니다. 실제 한국어 음성 생성과 파일 길이 확인을 수행했습니다.

## 사용자별 플러그인과 Codex

ChatGPT 로그인 후 공식 Codex 0.160.0의 `mcpServerStatus/list`로 실제 실행 도구를 조회합니다. Runway·Magnific·HeyGen·PixVerse만 표시합니다. 호스트 인증 정보를 가져오지 않으며 작업실에서 사용자가 승인한 로그인을 사용합니다.

- **ChatGPT 로그인**: 플러그인 → Codex 로그인에서 기기 인증을 시작하고, 공식 OpenAI 페이지에서 코드로 승인합니다. 작업실별 `CODEX_HOME`에 로그인 토큰을 보관하고 연결 해제 시 삭제합니다.
- API 키 연결도 선택할 수 있습니다. 키는 브라우저·프로젝트 파일에 저장하지 않고 서버 메모리에만 유지하며, API 사용료가 별도 적용됩니다.
- `CODEX_API_KEY`는 신뢰된 단일 사용자 배포의 운영자 기본 키입니다. 다중 사용자 배포에서는 사용자별 연결을 사용하세요.
- 운영자가 `PLUGIN_GATEWAY_URL`을 지정하고 사용자가 토큰으로 연결하면 계정별 `/v1/capabilities`에서 지원 기능을 조회합니다.
- **실행 도구 조회**: 도구 메타데이터와 읽기 전용 계정 확인으로 실행 연결·재인증 필요·도구 미노출을 구분합니다. 앱 디렉터리의 `app/list`만으로 연결 여부를 판단하지 않습니다.
- **Codex 직접 실행**: ‘Codex로 작업하기’ → 작업 지시와 F2F/참조 선택 → 전체 보고서 → 명시적 승인 → 실제 `mcpServer/tool/call` → 결과를 미디어로 가져오기. 별도 게이트웨이 키 없이 사용자 Codex 연결을 사용합니다. [실행 계약](docs/plugin-gateway.md).
- **승인 강제**: 추론 전용 Codex에는 네이티브 앱·셸·플러그인을 비활성화하고 제한된 동적 도구만 제공합니다. 실제 실행은 별도 프로토콜 클라이언트가 담당합니다. 모든 생성·업로드 호출은 승인 보고서의 정확한 도구/인자와 일치해야 하며 한 번만 실행합니다. 비용은 Codex 예상 또는 미확인으로 표시하고 확정 견적으로 주장하지 않습니다. 비용·자료 전송에 동의하지 않으면 실행하지 않습니다.
- F2F는 트림된 두 컷의 마지막·첫 프레임 JPG를 승인 후 전송합니다. Omni는 선택한 참조 소재를 사용합니다. 이미지 선행 생성도 별도 승인을 받고 결과 검토 후 영상 생성을 다시 요청합니다.

실제 구독 인증으로 Codex 추론 → Magnific 계정 조회 → 응답 수신을 확인했습니다. 실제 모델 목록·설정 조회 후 승인 보고서에서 멈추는 것도 검증했고 생성은 승인하지 않았습니다. 당시 Runway·HeyGen 호출은 재인증을 요청했고, PixVerse 실행 도구는 반환되지 않았습니다. 유료 생성·최종 결과 수신은 모의 실행기로 검증했으며 실제 유료 생성의 성공을 주장하지 않습니다.

## 저장과 운영 범위

개인 작업실용 구현입니다. 프로덕션 모드에서는 최초 설정 링크와 비밀번호 로그인이 필수이고, 인증된 소유권으로 미디어·프로젝트·Codex 연결을 묶습니다. 비밀번호는 솔트된 scrypt 해시로, 로그인 세션은 해시로 보관합니다. HttpOnly/SameSite 쿠키와 HTTPS에서는 Secure 쿠키를 사용합니다.

현재 작업실 데이터는 `.data/live-workspace/`에 있습니다. 프로젝트를 서버에 저장하므로 재로그인·다른 브라우저에서도 복원됩니다. 동시 편집 충돌은 덮어쓰지 않고 안내합니다. 업로드는 512 KiB 단위로 전송하며 최대 500MB입니다. CPU 작업 동시성도 제한합니다.

고정 호스팅·다중 계정 가입·결제·팀 협업·영속 작업 큐는 별도 운영 구성이 필요합니다. 공개 서버는 `COOKIE_SECURE=1`과 HTTPS를 유지하고, 임의 외부 Origin의 변경 요청은 거절합니다. 임시 연결의 수명과 데이터 경유에 관한 설명은 [접속 안내](docs/access.md)에 있습니다.

자동 음성 인식 자막, 마스크·키프레임 합성, LUT/스코프, 멀티캠, 비트 감지, 고급 J/L컷·트랜지션은 이번 구현에 포함되지 않습니다.
